# dy

一个用于管理 FLClash 订阅配置与安全访问的 Bash 脚本。

该脚本会在目标服务器上安装一个可执行命令 `dy`，用于：

- 导入或更新 FLClash 配置文件
- 查看当前安全订阅地址
- 修改订阅访问密钥
- 重新配置环境与域名
- 重启 Caddy 订阅服务

## 功能概览

- 支持从本地文件导入订阅配置
- 支持从远程 URL 下载并导入配置
- 自动读取 Caddy 配置中的 host 和 path 信息
- 生成或修改订阅访问路径密钥
- 调整订阅目录权限，减少未授权访问风险
- 通过 Caddy 配置进行安全增强和伪装策略

## 适用环境

- Linux 服务器
- 已安装 Caddy
- 配置文件位于 `/etc/caddy/Caddyfile`
- 订阅文件目录位于 `/var/www/sub`

## 安装
下载脚本：
 
   ```bash
   bash <(curl -sL https://raw.githubusercontent.com/bill-safe/dy/refs/heads/main/dy.sh)
   ```

## 说明

该脚本偏向于服务器端一键运维脚本，适合在已部署好 Caddy 的环境中快速管理 FLClash 订阅。请在生产环境中使用前确认：

- Caddy 配置正确无误
- 订阅目录具备必要读写权限
- 远程订阅 URL 来源可信
- 安全密钥和访问路径不泄露给未经授权的用户

## 备注

本项目是一个简化版的订阅管理脚本。若你在实际使用中需要进一步增强安全性，建议继续补充：

- 访问日志审计
- IP 白名单/黑名单
- 定时配置同步
- 更严格的 Caddy 访问策略
